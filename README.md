# Crazy-3d-Car-Game

A full-featured 3D arcade racing game built with React, Three.js, React Three Fiber (R3F), and TypeScript.

## Features
- **4 Diverse Tracks**:
  - Paradise Beach Coast (Coastal boulevard, palm trees & ocean)
  - Emerald Pine Forest (Highland mountain runs & pine groves)
  - Red Rock Canyon (Desert oasis & towering sandstone mesas)
  - Ultimate Adventure Safari (Mega jumps, wild animals, river rapids, mud bog, and glowing crystal cavern)
- **Extreme Adventure Mechanics**:
  - High-speed ramp jumps with ballistic airtime physics
  - Water hazards with splash particles & audio
  - Mud bog with slowing mud splatters
  - Animated elephants and giraffes
  - Crystal cave tunnel with glowing neon crystals
- **3 Distinct Arcade Cars**:
  - Apex GT (Balanced Sports Coupe)
  - Venom Viper-X (Drift King Supercar)
  - Phantom RS (Raw Speed Hypercar)
- **Dynamic Pre-race Roleplay**:
  - Handshake cutscene between driver and partner
  - Seated 3D character models inside car cockpit
- **Built-in Music Radio**:
  - 4 Procedural synth soundtracks + Custom audio/MP3 upload
- **Smart AI Opponents & Leaderboard**:
  - Real-time lap timings, delta gaps, and race records

## Tech Stack
- React 18
- Three.js / React Three Fiber (@react-three/fiber)
- Tailwind CSS
- Web Audio API (Procedural sound synthesis)
- TypeScript + Vite

## Getting Started
```bash
npm install
npm run dev
```
